# 00 Brand and Naming

## Series Name

- The series name is **座布団 (zabuton)**
- The GitHub organization is `zabuton-app`. Each app's repository lives at `zabuton-app/<romanized name>`

## App Naming Rules

Name a new app according to the following rules.

1. The name is **the continuative form (ren'yōkei) of a native Japanese verb (yamato kotoba)** (e.g. 巡り → meguri, 刻み → kizami)
2. **The romanized name is lowercase, based on Kunrei-shiki romanization**, and **must end with the vowel "i"**
3. The romanized name is used for the repository name, the package name (`name` in `package.json`), and the executable name
4. **The app's display name is the corresponding single kanji** (e.g. 巡). Use this kanji for every official name visible to users, such as the window title, the About section, and store listings
5. When using the romanized name in documentation or conversation, write it in lowercase (meguri) by default

## Relationship to the Logo

The single kanji of the display name is used directly as the logo motif. See [08 Logo](08-logo.md) for details.

## Official Character

The series has adopted a mascot modeled on a navy zabuton cushion as its official character. The mascot represents the series as a whole and does not replace each app's logo (a single kanji). See [12 Mascot](12-mascot.md) for details.
