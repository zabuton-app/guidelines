# 07 i18n

## Provider の API 形

i18n は自前実装（`src/i18n/`）で統一する。外部ライブラリは使わない。

- `I18nProvider` が `{ lang, setLang, t }` を提供する
- `t(key, params?)` は `{name}` 形式のプレースホルダ補間に対応する
- `LANGUAGES: { id: Lang; label: string }[]` を export し、設定画面の言語 Select が参照する
- 言語は `localStorage`（キー: `<app>.lang`）に永続化し、`document.documentElement.lang` に反映する
- 日本語カタログ（`locales/ja.ts`）を原典とし、他言語は `Record<TranslationKey, string>` で同型を強制する

## キー命名規約

`<ドメイン>.<名前>` の 2 階層で命名する。共通ドメインは以下。

| ドメイン | 用途 | 例 |
| --- | --- | --- |
| `common.*` | 汎用ボタン・操作 | `common.close`, `common.delete` |
| `app.*` | アプリ名・グローバル文言 | `app.title`, `app.newSession` |
| `settings.*` | 設定画面のセクション | `settings.language`, `settings.theme`, `settings.about` |
| `about.*` | About セクション | `about.version`, `about.ossTitle`, `about.license` |

- 説明文はラベルキー + `Desc` サフィックス（例: `settings.languageDesc`）
- アプリ固有の画面はドメインを切って揃える（巡: `home.*` / `workspace.*`）

## 共通文言

`settings.*` / `about.*` の共通キーの訳語はアプリ間で揃える（アプリ名部分のみ置換）。例: `settings.about` = 「このアプリについて」/ "About"。
